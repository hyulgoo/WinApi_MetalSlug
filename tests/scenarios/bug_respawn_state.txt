# 사용자 보고(2026-10-15): 리스폰해서 내려온 뒤 앉은 상태로 시작하는 경우가 있다
# 수정 전: 위·아래 보기를 키를 뗀 순간에만 풀어서, 죽어 있는 동안 키를 떼면 그 순간을 놓쳤다.
#          다시 나온 뒤에도 "아래를 보는" 상태가 남아 땅에서는 앉은 그림(BOW_IDLE), 위를 누르다 죽으면 위를 보는 그림으로 시작했다.
#          리스폰 때 몸 상태·사격 자세도 처음으로 돌리지 않았다
start STAGE
frames 17s
log 0
nospawn
# 앉은 채(↓) 죽고, 사망 연출 중에 ↓를 뗀다 → 다시 나와 내려오면 서 있어야 한다
hold 1s 3.5s DOWN
expect 1.8s player.anim == BOW_IDLE.anim
kill 2s
expect 7s player.anim == IDLE_UPPER.anim
expect 7s player.anim2 == IDLE_LOWER.anim
# 위(↑)를 보며 쏘다가 죽고 사망 연출 중에 ↑를 뗀다 → 다시 나오면 앞을 본다
hold 8s 10.5s UP
tap 8.8s C
kill 9s
expect 14.5s player.anim == IDLE_UPPER.anim
expect 14.5s player.anim2 == IDLE_LOWER.anim
expect end errors == 0
