# 보스: 박힌 비석은 위에서 내려올 때만 밟는 발판이다. 서 있으면 가라앉는 만큼 따라 내려가고, 끝에서 걸어 내려온다
# 무적일 때 비석이 몸 위에 박히면 옆으로 밀려난다 (가까운 옆이 화면 밖이면 반대쪽으로). 수류탄은 맞을 때마다 열 장(sink_grenade)
start STAGE
frames 18s
log 0
god 1 1
data boss boss first_wait_time 6
data boss boss wait_time 6
data boss beam track_speed 0
camera 0.5s 5150
# 보스가 나온 뒤 카메라를 스테이지 끝(실제 보스전의 자리)으로
camera 0.55s 5182
# 화면 왼쪽 끝 가까이(x 60)에 서 있다가 비석이 몸 위에 박힌다(11.8초쯤).
# 깔림 판정이 지난 뒤 밀려나는데, 왼쪽 옆은 화면 밖이라 오른쪽 옆(60 + 115.5 + 몸 폭 절반 40)으로
teleport 9s 60 600
expect 11.7s player.x < 61
expect 12.5s player.x > 215
expect 12.5s player.x < 216
# 비석 쪽(왼쪽)을 보고 수류탄을 던진다
hold 12.6s 12.65s LEFT
tap 12.8s Z
expect 13.3s first.CMonolith.frm == 10
tap 13.3s Z
expect 13.9s first.CMonolith.frm >= 20
# 낮아진 비석에 왼쪽으로 뛰어 올라선다
tap 14.8s X
hold 14.8s 15.2s LEFT
expect 15.5s player.y < 580
expect 15.5s player.anim2 == IDLE_LOWER.anim
# 오른쪽 끝에서 걸어 내려온다 (몸이 윗면에서 다 벗어나야 떨어지고, 옆면으로 튕겨 나가지 않는다)
hold 15.7s 16.3s RIGHT
expect 16.6s player.y > 650
expect 16.6s player.x > 255.5
expect 16.6s player.x < 400
# 다 가라앉으면 돌무더기를 남기고 사라진다
expect end deleted.CMonolith >= 1
expect end errors == 0
