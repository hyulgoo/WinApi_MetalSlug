# 수동 점검표

리팩토링 단계를 마칠 때마다 사람이 직접 한 번 해 보는 순서다.
같은 흐름을 자동으로 도는 시나리오는 `tests/scenarios/checklist_flow.txt` 이고, 자동 테스트로 확인하기 어려운 것(화면이 자연스러운지, 소리·조작감)만 여기서 눈으로 본다.

## 준비

- `OutputFile\bin\content\texture\` 에 스프라이트 시트가 있어야 한다(저장소에 넣지 않는다. README 참고)
- Debug 빌드는 디버그 키가 켜져 있다. Release 빌드에서는 디버그 키가 동작하지 않아야 한다

## 순서

| # | 할 일 | 확인할 것 |
| --- | --- | --- |
| 1 | 실행 | 타이틀(캐릭터 선택)에서 시작한다. 바로 스테이지로 가지 않는다 |
| 2 | ← → | 선택 표시가 바뀐다 |
| 3 | C | 셔터가 내려오고 화면이 어두워진 뒤 스테이지가 밝아진다. 흔들림이 스테이지까지 남지 않는다 (타이틀의 카메라 흔들림은 원래 코드에서도 보이는 오브젝트에 적용되지 않아 화면이 흔들리지 않는다) |
| 4 | 소환 | 소환 연출 뒤 조작할 수 있다. 권총(∞), 폭탄 10, 시간 59 |
| 5 | → 로 진행 | 카메라가 지형을 따라 움직이고 캐릭터가 화면 안에 있다. 몬스터·투사체·이펙트가 배경에 붙어 있다 |
| 6 | C 연타 / 누르기 | 권총이 나간다. 몬스터에 붙으면 칼로 벤다(짧게 눌러도 맞는다. ↑를 누르고 있어도 앞을 벤다). 칼 범위에서는 총알이 섞이지 않는다 |
| 7 | Z 열 번 | 폭탄이 열 번 모두 나간다. C를 누른 채로도 나간다. 0개면 던지지 않는다. 폭탄은 한 번 낮게 튀고 다시 땅에 닿을 때 바닥에서 터진다. ↑를 누르거나 공중에서 ↓를 누르고 던져도 옆을 보고 던질 때와 같은 손 위치에서 나간다 |
| 8 | X, ↓, ↑ | 점프, 앉기(앉아 걷기), 위 보기. 상체·하체가 떨리지 않는다 |
| 9 | 아이템 | 연구원 좀비가 떨어뜨린 상자로 HMG 또는 폭탄이 는다 |
| 10 | 사망 | 맞으면 사망 연출 뒤 위에서 소환된다. 목숨이 1 준다. 앉거나 위를 보던 채 죽어도 다시 나오면 서서 앞을 본다 |
| 11 | 목숨 0 | 화면의 목숨이 0이어도 계속 플레이한다. 0에서 죽으면 사망 연출 뒤 게임오버 화면. C를 2초 누르면 타이틀로 |
| 12 | 다시 시작 | 타이틀이 처음과 같고(선택 화면이 보인다) 다시 시작해도 칼이 맞는다 |
| 13 | F1(타이틀) | 애니메이션 에디터로 간다 |
| 14 | 에디터 | `< Sheet`·`Sheet >`로 시트를 고르고, 드래그로 프레임을 만들고(패널 버튼을 눌러도 프레임이 생기지 않는다), 저장·불러오기·프레임 삭제(DEL)·순서(J/L)·되돌리기(Ctrl+Z)가 된다. 오른쪽 드래그·화살표로 시트를 옮긴 뒤에도 사각형이 그림에 맞는다. TAB·Ref Load로 상체를 하체 위에 겹쳐 볼 수 있다 |
| 15 | F4(에디터) | 타이틀로 돌아온다. 다시 에디터에 들어가도 정상이다 |
| 16 | 1~15 반복 | 두 번째 바퀴도 첫 바퀴와 같다. 작업 관리자의 GDI 개체 수가 늘지 않는다 |
| 17 | Release 빌드 | F·V·Q·R·WASD·ENTER(스테이지) 디버그 키가 동작하지 않는다. 좌표 표시가 없다 |
| 18 | 몬스터 공격·사망 | 좀비의 토사물, 병사의 수류탄·칼이 공격 동작의 그 순간에 나간다. 사망 이펙트(불탄 좀비 포함)가 끝까지 재생된 뒤 사라진다 |
| 19 | 창 끌기·최소화 | 스테이지에서 창 제목 표시줄을 몇 초 끌거나 최소화했다가 돌아와도 캐릭터가 바닥을 뚫거나 재소환되지 않는다. 작업 관리자에서 CPU가 코어 하나를 다 쓰지 않는다(60 FPS 제한), 최소화 중에는 거의 0 |
| 20 | 에디터 대화상자 | 메뉴 "애니메이션 → 격자로 프레임 추가..."와 `Grid Add` 버튼이 같은 대화상자를 연다. 빈 칸·크기 0·시트 밖이면 이유를 알리고 닫히지 않는다. 저장에서 확장자 없이 이름을 쓰면 `.anim`이 붙고, 있는 파일이면 덮어쓸지 묻는다. 파일을 더블클릭해 열어도 그 클릭으로 프레임이 생기지 않는다 |
| 21 | 에디터 → 게임 | 에디터에서 `Player\IDLE_UPPER.anim`의 재생 시간을 바꿔 같은 파일에 저장한 뒤 F4 → C로 들어가면 바로 바뀌어 있다(다시 실행하지 않아도). 확인 뒤 `git checkout`으로 되돌린다 |
| 22 | 데이터 파일 | 게임을 켠 채(타이틀 화면에서) `OutputFile\bin\content\data\player.ini`의 `[move] speed`를 660으로 고쳐 저장하고 C로 스테이지에 들어가면 두 배로 빨리 걷는다(레벨에 들어갈 때 다시 읽는다). 숫자 대신 글자를 넣으면 오류 창이 한 번 뜨고 움직이지 않는다. 확인 뒤 `git checkout`으로 되돌린다 |
| 23 | 보스 등장 | 스테이지 끝까지 가면(Debug는 WASD로 빨리, 또는 타이틀에서 F2) 배경의 돌무덤 자리에서 돔이 먼지 기둥 사이로 솟아오르고 화면이 흔들린다. 땅 아래 부분은 보이지 않는다. 다 올라오기 전에는 쏴도 체력이 줄지 않는다. 흔들리는 동안 카메라를 밀어도 끝 자리에서 멈춘다 |
| 24 | 빛기둥·빔·비석 | 돔이 빛기둥을 쏘면(돔 자리에 정확히 겹친다) 가는 빔이 하늘에서 내려와 플레이어를 따라오다 멈추고, 빔이 사라진 뒤에 그 자리로 비석이 떨어져 화면이 흔들린다(떨어지는 비석이 빔을 지나가지 않는다). 그 자리에 있으면 죽고, 피하면 산다. 박힌 비석은 걸어서도 뛰어서도 지나갈 수 없고, 옆에 붙어 비석 쪽을 누르면 그쪽을 본다. 비석을 쏘면(박힌 직후에도) 맞을 때마다 눈에 띄게 내려가고, 수류탄은 더 많이 내려간다. 가라앉는 동안 비석이 옆으로 움직이지 않는다(윗줄 글자 자리가 그대로). 충분히 낮아진 비석에는 뛰어 올라설 수 있고, 선 채로 같이 내려가며, 끝으로 걸어가면 옆으로 튕기지 않고 내려온다 |
| 25 | 보스 격파 | ↑+C로 돔을 쏜다(땅에서 옆으로 쏘면 맞지 않는다). 맞을 때마다 돔만 빨갛게 깜빡이고 받침대는 그대로다(솟아오르는 동안에는 깜빡이지 않는다). 부서지면 돔이 깨진 잔해 위로 폭발이 이어지고 남은 비석이 빨리 가라앉는다. 플레이어가 승리 포즈를 하고 몇 초 뒤 화면이 어두워지며 타이틀로 돌아간다 |
| 26 | 보스전부터 시작 | 타이틀 아래 도움말에 `F2 : BOSS`가 보인다. F2를 누르면 C와 같은 선택 연출 뒤 스테이지 끝(돌무덤 앞)에서 시작하고 바로 보스가 솟아오른다. 앞의 좀비·병사는 나오지 않는다. 오른쪽으로 걸으면 카메라가 끝 자리까지 밀린다. 타이틀로 돌아와 C를 누르면 처음부터 시작한다 |

## 디버그 키 (Debug 빌드만)

| 키 | 레벨 | 동작 |
| --- | --- | --- |
| Q | 스테이지 | 충돌체 표시 켜기·끄기 |
| R | 스테이지 | 픽셀 충돌 맵 표시 켜기·끄기 |
| V | 스테이지 | 무적 켜기·끄기 |
| F | 스테이지 | 승리 포즈 |
| W A S D | 스테이지 | 플레이어 순간 이동(디버그) |
| ENTER | 스테이지 | 애니메이션 에디터로 |
